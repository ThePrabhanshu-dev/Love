HOW TO CUSTOMIZE YOUR SURPRISE WEBSITE

This folder already works as-is: image1.jpg–image6.jpg are filled with soft generated
heart-glow placeholder art (matching the site's colors), and romanticMusic.mp3 is a
short generated ambient piano loop — just so the site feels complete immediately.
Swap both out whenever you're ready:

1. PHOTOS
   Replace the files inside the "images" folder, keeping the exact names:
   image1.jpg, image2.jpg, image3.jpg, image4.jpg, image5.jpg, image6.jpg
   (jpg, jpeg, png and webp all work as long as the filename + extension match what's in script.js)

2. MUSIC
   Replace the file inside the "music" folder, keeping the exact name:
   romanticMusic.mp3
   Music will not autoplay — she taps the "Open Your Surprise" button, which starts it.

3. TEXT
   Open script.js in any text editor. Right at the top you'll find a block called CONFIG.
   Every headline, message, caption, timeline entry, and button label lives there in plain English —
   change any line inside the quotes and save. You never need to touch the HTML or CSS.

4. VIEWING IT
   Just open index.html in a browser (double-click it). No install, no server, no internet needed
   except for the two Google Fonts loaded from index.html.

5. SHARING IT
   Keep index.html, style.css, script.js, and the images/music folders together in the same folder
   when you upload or send it anywhere (e.g. Netlify, Vercel, GitHub Pages, or just zip the whole folder).
